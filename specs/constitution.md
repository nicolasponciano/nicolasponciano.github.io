# Constitution do projeto

Regras para as specs e a implementação deste portfólio.

## Stack e convenções
- Stack proposta para aprovação: HTML, CSS e JavaScript sem framework, com publicação estática.
- Specs, conteúdo e interface em português do Brasil; nomes de código em inglês quando forem convenção técnica; seguir a estrutura existente.
- Manter o conteúdo do portfólio separado da lógica de animação.

## Proibições
- Não copiar nome, foto, textos, projetos, identidade visual ou contatos do site de referência.
- Não usar serviço externo ou API para simular agentes; os cursores são animação local, não agentes de IA.
- Não adicionar dependência sem registrar e aprovar a decisão na spec.

## Qualidade
- Interações têm critério verificável e controles por teclado; respeitar `prefers-reduced-motion` e oferecer conteúdo sem animação.
- Executar uma tarefa por vez; mudança de escopo atualiza a spec; rodar as verificações disponíveis e só marcar tarefa concluída após validar seus critérios.
